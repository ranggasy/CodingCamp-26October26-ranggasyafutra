# Spendly 💸

**YOUR MONEY, CLEARER.**

Spendly is a simple, responsive expense and budget visualizer designed to help users track daily expenses, monitor total spending, and understand their spending habits through visual charts.

Built as a project for **RevoU Coding Camp**, Spendly uses HTML, CSS, and Vanilla JavaScript without a backend.

## ✨ Features

### Core Features
- **Add Transactions** – Record daily expenses with transaction names, amounts, and categories.
- **Expense Categories** – Organize transactions into three fixed categories:
  - Food
  - Transport
  - Fun
- **Total Spending** – Automatically calculate total expenses.
- **Transaction List** – View recorded transactions with their names, amounts, categories, and dates.
- **Delete Transactions** – Remove transactions when they are no longer needed.
- **Pie Chart Visualization** – Visualize expense distribution across categories using Chart.js.
- **Local Storage** – Automatically save transactions in the browser so data remains available after refreshing the page.

### Additional Features
- **Dark & Light Mode** – Switch between themes.
- **Monthly Summary** – View monthly spending totals and category breakdowns.
- **Transaction Sorting** – Sort transactions by default order, amount ascending, amount descending, or category.

## 💾 Data Storage

Spendly uses the browser's **Local Storage** to store transaction data.

- Transactions are saved locally in the browser.
- Data persists after refreshing the page.
- Data is stored per browser and device.
- Clearing browser storage may remove saved transactions.
